# Infraestructura

Plantillas de infraestructura como código (Bicep) para Azure. Se preparan en la **Fase 10**.

Recursos previstos:

- Azure App Service (Linux) para la API
- Azure SQL Database
- Azure Storage Account con un container privado para las imágenes
- Key Vault para los secretos
- Application Insights (opcional)

> No hay despliegue automático. Las plantillas se aplicarán manualmente o desde un pipeline futuro.
